---PAGES RELATED TO ARTISTS---


REQUEST: api/1.0/artists
GET parameters: None

RESPONSE: A JSON list containing a dictionary representing each artist.
Each dictionary contains the artist name and ID.

EXAMPLE: api/1.0/artists
[{"artistID": 1, "artistName": "ABBA"}, {"artistID": 2, "artistName": "La Bottine Souriante"}, {"artistID": 3, "artistName": "Paul Simon"}]

REQUEST: api/1.0/artists/<artistID>
GET parameters:
- artist (Required): the name of the artists selected from the list of artists in the /1.0/artists endpoint

RESPONSE: A json list that contains a dictionary for each album by that artist.
Each dictionary contains the fields album ID, album name, and album year.

EXAMPLE: api/1.0/artists/2
[{"albumID": 4, "albumName": "Cordial", "albumYear": 2001}, {"albumID": 5, "albumName": "En Spectacle", "albumYear": 2006}]

REQUEST: api/1.0/artists/<artistID>/songs?shuffle=shuffle
GET parameters:
- artist (Required): the name of the artists selected from the list of artists in the /artists endpoint
- shuffle (Optional, default = false): tells the database to return the list of songs by the artist in a randomized order (based on the tracknumbers)

RESPONSE: A JSON list that contains one dictionary for each album by the specified artist.
If shuffle = true then return this list in a randomized order.

EXAMPLE: api/1.0/artists/3?shuffle=false

[{"albumID": 7, "albumName": "Graceland", "albumYear": 1986}, {"albumID": 6, "albumName": "So Beautiful or So What", "albumYear": 2011}, {"albumID": 8, "albumName": "There Goes Rhymin' Simon [Bonus Tracks]", "albumYear": 2004}]


---PAGES RELATED TO ALBUMS---


REQUEST: api/1.0/albums
GET parameters: None

RESPONSE: A JSON list containing a dictionary representing each album. Each dictionary contains the album name and ID.

EXAMPLE: api/albums
[{"albumID": 1, "albumName": "Gold - Greatest Hits", "albumYear": 1993}, {"albumID": 2, "albumName": "The Definitive Collection Disc 1", "albumYear": 2001}, {"albumID": 3, "albumName": "The Definitive Collection Disc 2", "albumYear": 2001}, {"albumID": 4, "albumName": "Cordial", "albumYear": 2001}, {"albumID": 5, "albumName": "En Spectacle", "albumYear": 2006}, {"albumID": 6, "albumName": "So Beautiful or So What", "albumYear": 2011}, {"albumID": 7, "albumName": "Graceland", "albumYear": 1986}, {"albumID": 8, "albumName": "There Goes Rhymin' Simon [Bonus Tracks]", "albumYear": 2004}]

REQUEST: api/1.0/albums/<albumID>?shuffle=shuffle
GET parameters:
- album (Required): the name of the album selected from the list of albums in the /1.0/albums endpoint
- shuffle (Optional, default = false): tells the database to return the list of songs on the album in a randomized order (based on the Tracknumbers)

RESPONSE:
A JSON list that contains a dictionary for each song in the specified album. If shuffle = true then returns the songs in a randomized order. The URL redirects based on the album artist that is stored as a parameter to the album object (accessible through IDs).

EXAMPLE: api/1.0/albums/1?shuffle=false
[{"songID": 6, "songName": "Mamma Mia", "trackNumber": 4, "songLength": 213493, "songBPM": 0}, {"songID": 7, "songName": "The Name of the Game", "trackNumber": 17, "songLength": 240000, "songBPM": 0}, … (rest of songs on album in order)]


---PAGES RELATED TO SONGS---


REQUEST: api/1.0/songs
GET parameters:
- shuffle (Optional, default = false): tells the database to return the list of songs in a randomized order (based on the songID)
RESPONSE: A JSON list containing a dictionary representing each song. Each dictionary contains entries for the song ID, title, track mumber, length, and BPM.

EXAMPLE: api/1.0/songs
[{"songID": 70, "songName": "A Bas Les Rideaux (Out with the Lies)", "trackNumber": 10, "songLength": 232493, "songBPM": 0, "artistName": "La Bottine Souriante", "albumName": "Cordial"}, {"songID": 64, "songName": "Aim\u00e9", "trackNumber": 6, "songLength": 221626, "songBPM": 0, "artistName": "La Bottine Souriante", "albumName": "Cordial"}, ... (the rest of the songs)]
REQUEST: api/1.0/songs/<songID>
GET parameters: None

RESPONSE: Responds with all the data about a single song

EXAMPLE: api/1.0/songs/1
[{"songid": 1, "songname": "Take a Chance on Me", "tracknumber": 3, "songlength": 244466, "songbpm": 0, "artistname": "ABBA", "albumname": "Gold - Greatest Hits"}]
