---PAGES RELATED TO ARTISTS---

REQUEST: /1.0/artists
GET parameters: None

RESPONSE: A JSON list containing a dictionary representing each artist.
Each dictionary contains the artist name and ID.

EXAMPLE: /1.0/artists
[{“artistName”: “ABBA”, “artistID” = 0001}, {“artistName”: “La Bottine Souriante”, “artistID” = 0100},{“artistName”: “Paul Simon”, “artistID” = 1101}]

REQUEST: /1.0/artists/<artistName>
GET parameters:
- artist (Required): the name of the artists selected from the list of artists in the /1.0/artists endpoint

RESPONSE: A json list that contains a dictionary for each album by that artist.
Each dictionary contains the fields album ID, album name, and album year.

EXAMPLE: /1.0/artists/La%20Bottine%20Souriante
[{"albumID": 10010, "albumName": "Corial", "albumYear": 2001}, {"albumID": 11011, "albumName": "En Spectacle", "albumYear": 1996}]

REQUEST: /1.0/artists/<artistName>/songs?shuffle=shuffle
GET parameters:
- artist (Required): the name of the artists selected from the list of artists in the /artists endpoint
- shuffle (Optional, default = false): tells the database to return the list of songs by the artist in a randomized order (based on the tracknumbers)

RESPONSE: A JSON list that contains one dictionary for each song by the specified artist.
If shuffle = true then return this list in a randomized order.

EXAMPLE: /1.0/artists/Paul%20Simon?shuffle=false

[{song1 by Paul Simon}, {song2 by Paul Simon}, ...]

REQUEST: /1.0/artists/<artistName>/<albumName>?shuffle=shuffle
GET parameters:
- artist (Required): the name of the artists selected from the list of artists
in the /1.0/artists endpoint
- album (required): the name of the specified album by the specified artist from the list of albums on the /1.0/artists/<artist> page
- shuffle (Optional, default = false): tells the database to return the list of songs on the album in a randomized order (based on the Tracknumbers)

RESPONSE: A JSON list which contains a dictionary to represent every song by the specified artist on the specified album. If shuffle = true, then returns this list in a randomized order.

EXAMPLE: /1.0/Paul%20Simon/Kodachrome?
[{“song1 ID”: 0100101, "album": "There Goes Rhymin' Simon [Bonus Tracks]", "length": "215400", "title": "Kodachrome", "artist": "Paul Simon", "tracknumber": "1", "date": "2004"}, … (rest of songs on the album in order)]

---PAGES RELATED TO ALBUMS---

REQUEST: /1.0/albums
GET parameters: None

RESPONSE: A JSON list containing a dictionary representing each album. Each dictionary contains the album name and ID.

EXAMPLE: /albums
[{"albumName": "Cordial", "albumID": 01}, {"albumName": "En Spectacle", "albumID": 0101} {"albumName": "Gold - Greatest Hits", "albumID": 011001}, {"albumName": "Graceland", "albumID": 011001}, {"albumName": "So Beautiful or So What", "albumID": 10101}, {"albumName": "The Definitive Collection Disc 1", "albumID": 10101001}, {"albumName": "The Definitive Collection Disc 2", "albumID" : 1011001}, {"albumName": "There Goes Rhymin' Simon [Bonus Tracks]"", "albumID": 1011001}]

REQUEST: /1.0/albums/<albumName>?shuffle=shuffle
REDIRECTS TO: /1.0/artists/<artist>/<album>?shuffle=shuffle
GET parameters:
- album (Required): the name of the album selected from the list of albums in the /1.0/albums endpoint
- shuffle (Optional, default = false): tells the database to return the list of songs on the album in a randomized order (based on the Tracknumbers)

RESPONSE:
A JSON list that contains a dictionary for each song in the specified album. If shuffle = true then returns the songs in a randomized order. The URL redirects based on the album artist that is stored as a parameter to the album object (accessible through IDs).

EXAMPLE: /1.0/albums/The%20Definitive%20Collection%20Disc%202?shuffle=true [{“songID”: 01110, "album": "The Definitive Collection Disc 2", "length": "259933", "title": "Angeleyes", "artist": "ABBA", "tracknumber": "2", "date": "2001"}, … (rest of songs on album in random order)]

---PAGES RELATED TO SONGS---

REQUEST: /1.0/songs
GET parameters: None

RESPONSE: A JSON list containing a dictionary representing each song. Each dictionary contains entries for the song ID, title, track mumber, length, and BPM.

EXAMPLE: /1.0/songs
[{song1 with parameters}, {song2 with parameters}, ...]
